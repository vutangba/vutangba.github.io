# Portfolio - Vũ Tăng Ba

Chào mừng bạn đến với trang cá nhân của mình. Mình là sinh viên ngành Kỹ thuật tại HUIT.

## 🛠 Dự án tiêu biểu
### 1. Robot giải Rubik
* **Mô tả:** Nghiên cứu và chế tạo Robot giải Rubik sử dụng giải thuật Kociemba.
* **Công nghệ:** Arduino Mega, RAMPS 1.6, Python (OpenCV).

### 2. Tự động hóa & Điện công nghiệp
* Thiết kế tủ điện ATS, lập trình PLC TIA Portal.
* Bóc tách khối lượng vật tư (BOQ).

## 🚀 Kỹ năng
* **Phần mềm:** AutoCAD, Fusion 360, MATLAB, TIA Portal.
* **Lập trình:** Python, C++ (Arduino).
